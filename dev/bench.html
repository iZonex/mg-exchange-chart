What this measures

Canvas 2D: Per-bar JS loop — fillRect for body, beginPath/stroke for wick. Browser GPU-accelerates internally via Skia (Chrome) or Metal (Safari).

WebGL: Raw OHLCV prices uploaded to GPU as Float32Array. Dedicated vertex shader computes pixel coordinates on GPU. 12 vertices per candle (body quad + wick quad). Total: 2 draw calls (candles + volume) regardless of bar count.

gl.finish() is called after WebGL rendering to force GPU synchronization, ensuring we measure actual GPU work, not just command buffer submission.
